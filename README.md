# AI Teacher's Toolkit (VedaAI Exams)

Next.js app: upload a question paper and a handwritten answer sheet, extract questions and answers, map them, optionally grade, and review with bounding-box overlays.

## Getting Started

1. Copy `.env.example` to `.env.local` and set `GROQ_API_KEY`.
2. `npm install`
3. `npm run dev`

Open [http://localhost:3000](http://localhost:3000).

See `PRD.md` and `tasks/` for the full spec and implementation plan.
